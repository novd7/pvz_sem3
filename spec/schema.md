# Контракт CSV для 1С

Используйте весь ZIP из `GET /api/exports/operations` как один снимок. Сервер читает четыре файла при одном согласованном срезе PostgreSQL. В комплект входят только точки, видимые текущей учётной записи: своя точка сотрудника, регион супервайзера или вся сеть аналитика.

| Файл | Заголовок | Значения |
|---|---|---|
| `snapshot.csv` | `snapshot_id,exported_at` | Ровно одна строка. UUID и дата-время ISO 8601 со смещением UTC |
| `pvz.csv` | `pvz_id,address,region_id,capacity_per_hour` | Целочисленные ID, текстовый адрес, положительная мощность |
| `schedule.csv` | `pvz_id,weekday,open_time,close_time` | День 0–6 от понедельника, время `HH:mm:ss`. `24:00:00` — конец суток. Начало включительно, конец исключительно |
| `operations.csv` | `op_id,pvz_id,ts,type` | Уникальный ID, ID точки, ISO 8601 со смещением UTC, тип `in`, `out`, `return` или `return_dispatch` |

Кодировка UTF-8 без BOM. Разделитель — запятая. Конец записи — CRLF. Поле с запятой, кавычкой или переносом заключается в двойные кавычки, кавычки внутри удваиваются. Строки `return_dispatch` — аудит и в нагрузку не входят. Для группировки используйте рабочие часы в Europe/Moscow.

Номер и время также передаются в заголовках `X-Snapshot-Id` и `X-Snapshot-Time`. Для проверки повтора в 1С импортируйте один скачанный ZIP дважды. Новое скачивание создаёт новый UUID. На стороне 1С запланированы проверка целого комплекта, защита от дублей и сохранение предыдущего набора при ошибке. [ADR-001](../docs/adr/001-csv-snapshot.md)
