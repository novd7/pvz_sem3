**Кейс 9 «Пункты выдачи маркетплейса»**

Автор: Владимир Новиков.

## Сайт и данные

В локальной версии работает сценарий приёмки от входа до выгрузки данных для 1С. Сайт и REST API обслуживает Spring Boot, данные хранятся в PostgreSQL 16. Flyway применяет миграцию V1 при запуске. Сайт и база запускаются через Docker Compose. [Сайт «Мой ПВЗ»](http://localhost:8080/) · [Схема БД](../../docs/database-schema.md) · [API](../../spec/openapi.yaml)

| Раздел | Данные и возможности |
|---|---|
| Вход | Сотрудник видит свою точку, супервайзер — точки своего региона, аналитик — всю сеть. Приёмка доступна сотруднику. |
| Главная сотрудника | Адрес точки, количество отправлений на складе и ожидаемых отправлений, общее число заказов и число ячеек со свободным местом. В таблицах отображаются последние операции, заказы и свободный объём ячеек. |
| Приёмка | Поиск отправления по коду, просмотр статуса и объёма, выбор подходящей ячейки. Сервер проверяет точку, расписание, статус и вместимость. Статус, размещение и операция сохраняются в одной транзакции. Повтор с тем же ключом возвращает прежний результат. |
| Снимок для 1С | ZIP с `snapshot.csv`, `pvz.csv`, `schedule.csv` и `operations.csv`. Снимок содержит номер и время создания, а данные ограничены областью доступа пользователя. Приёмка отражается в операциях строкой типа `in`. |

Экран входа, главная и форма приёмки оформлены по [прототипу «Мой ПВЗ»](../../ui-proto/ПД%202026%20ПВЗ.png). На телефоне боковое меню сворачивается, карточки располагаются вертикально.

В учебном наборе три ПВЗ в двух регионах, расписания, ячейки, отправления и учётные записи трёх ролей. На исходном наборе приёмка `DEMO-001` объёмом 3 л в ячейку №1 вместимостью 10 л переводит отправление в статус «На хранении». В ячейке остаётся 7 л свободного места, в журнале появляется одна операция. [Формат снимка](../../spec/schema.md)

## Проверки и статус реализации

- Проверены сборка, применение V1 на чистой PostgreSQL, запуск в Docker Compose и вход. Интерфейс проверен в Chrome на десктопном и мобильном размерах.
- Через API подтверждены ограничения по ролям, отказ при закрытом ПВЗ или недостатке места, повтор с тем же ключом и конфликт при смене данных с тем же ключом. Из двух одновременных запросов на последнее место в ячейке прошёл один.
- Сценарий подтверждён до скачивания CSV. В репозитории есть [файл конфигурации 1С](../../src-1c/1Cv8.cf). Для закрытия Gate‑2 требуется подтверждённый импорт этого снимка, сверка строки отчёта и проверка повторной загрузки. Контрольная дата — **17.11.2026**.
- Выдача, возврат, обратная отгрузка и создание заказов и ячеек через сайт остаются в плане. [Результаты проверок](../../docs/acceptance.md) · [План работ](../../docs/delivery-plan.md)
