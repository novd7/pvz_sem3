WP-QA объединяет сквозные работы. Генератор тестовых данных используется при разработке и приёмке. Связи рабочих контейнеров показаны на [C4 L2](c4-container.md).

Детальная оценка ниже укрупнённой на 5 ч (6%). По API разница 2 ч за счёт общей реализации прав, журналирования и повторов. По сайту, БД и 1С разница по 1 ч за счёт общих экранных компонентов, существующей V1 и переиспользования одной формы импорта. Сквозные работы остались на 25 ч. Суммы считаются по непересекающимся задачам. [Расчёт по задачам](delivery-plan.md)
