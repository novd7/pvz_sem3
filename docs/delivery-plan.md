## Критический путь

**T-06 → T-10 → T-11 → T-12 → T-13 → T-14 → T-21 → T-22 → T-23 — 31 ч** по сети зависимостей. Прямой проход берёт максимум раннего окончания предшественников, обратный берёт минимум позднего старта последователей. Резерв в таблице равен разнице позднего и раннего старта. Нулевой резерв отмечает задачи, задержка которых удлиняет сетевой расчёт. Часы CPM используют длительность работы одного исполнителя без календарных пауз и конкуренции за его время.

Гипотеза для планирования — до 16 ч на человека в каждой недельной итерации, включая резерв. Это потолок, фактическую доступность подтверждает команда. Плановые задачи занимают до 12 ч на человека за итерацию, остаётся минимум 4 ч (25% при ёмкости 16 ч). При доступности 8 ч в неделю запланированные часы превышают ёмкость у части команды. Перед обещанием даты нужно проверить доступ к 1С, ежедневную доступность и порядок передачи результатов между исполнителями. Опоздание Gate‑2 сдвигает зависимые работы W6.
