# Протокол рабочего совещания № 1

**Проект:** система учёта товаров и анализа загрузки ПВЗ, кейс 9.  
**Отчётный период:** 2–8 ноября 2026 года, W3.  
**Тема:** готовность данных, каркаса и материалов для интеграции.  
**Ведущий по роли:** Владимир Новиков. Фактическая дата, ведущий и присутствовавшие подлежат подтверждению командой.

Проект протокола восстановлен по отчёту Владимира, истории репозитория и дорожной карте. Решения, поручения и сроки ниже предложены для согласования.

## Повестка и состояние работ

1. **Сервер и БД.** Отчёт от 02.11 фиксирует создание Spring Boot проекта и работу над структурой БД. Коммит `af3780d` от 03.11 содержит каркас, SQL-миграцию V1 и документацию с ERD. Протокол успешного запуска и применения миграции отсутствует.
2. **Материалы W3.** По Roadmap нужны BPMN, ERD и описание данных, 3–5 макетов экранов, тестовые наборы T2/invalid и черновой импорт 1С. Из этого перечня по локальным файлам подтверждаются ERD и описание схемы.
3. **Подготовка W4.** Контрольная точка требует показать одну операцию до отчёта «Загрузка ПВЗ». Предлагается использовать приёмку из UC‑01 и проверить связку фронтенда, API, PostgreSQL, CSV и 1С на тестовой точке.

## Решения к подтверждению

- Взять структуру V1 за основу для проверки API и формата CSV совместно с Николаем и Эллой.
- На параллельных направлениях использовать пример API для UI и тестовые CSV для 1С. На W4 собрать их в единый прогон.
- Проверять закрытие задач по ссылке на артефакт или результат прогона.
