# Протокол рабочего совещания № 2

**Проект:** система учёта товаров и анализа загрузки ПВЗ, кейс 9.  
**Отчётный период:** 9–15 ноября 2026 года, W4.  
**Тема:** проверка готовности Gate‑2 и план работ после W4.  
**Ведущий по роли:** Владимир Новиков. Фактическая дата, ведущий и присутствовавшие подлежат подтверждению командой.

Проект протокола составлен по состоянию локальной ветки `develop` на 15.11. Общий срок следующего контроля — 17.11.2026. Назначения участников требуют подтверждения команды. Статусы ниже отражают наличие результатов в просмотренных материалах.

## Решения к подтверждению

- Сверить П‑02…П‑06 с GitVerse и материалами участников. По каждому переносу записать причину, владельца и новый срок.
- Собрать доказательство Gate‑2 на одной тестовой операции по UC‑01. Для отчёта показать ID операции, рабочий час и значение нагрузки. Отдельно проверить повторный импорт того же снимка по AC‑07.
- Параллельно закрыть архитектурные пункты практик 5–6. За основу взять границы из C4 Context и требования ПВЗ. После разбивки по пакетам и задачам проверить календарь до MVP 01.12.
